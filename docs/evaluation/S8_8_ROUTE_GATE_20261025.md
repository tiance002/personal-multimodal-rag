# S8-8 路由闸门实验（2026-10-25）

> 隐私说明：本文只记录方法与结果，不含题目原文、gold 答案与模型输出。评测数据保存在 `var/`（未入库）。

## 目的

验证「先用便宜模型跑全部题，再把错题交给贵模型重答」这条路由是否成立，并量出闸门（判定哪些题算错）的精度。

## 设置

| 项 | 值 |
|---|---|
| 题集 | S8-8 R2 的 55 题 |
| 提示词 | 两侧一致，`EN_SYSTEM_PROMPT`（1257 字符），经只读挂载注入容器 |
| cheap | `XingChenAGI/Xing4.0-29B`，`CHEAP_ONLY` 通道 |
| expensive | `deepseek-flash`，`EXPENSIVE_ONLY` 通道 |
| 采集 | cheap 55/55；贵模型两批共 13 题；全部一次通过、零重试 |

两条通道共用同一数据库、同一检索配置、同一镜像，唯一变量是模型角色。
真值由 55 题逐题独立复核确定，机器判分只作为闸门被评估。

## 结果

| 口径 | 正确 | 正确率 |
|---|---|---|
| 只跑 cheap | 47 / 55 | 85.5% |
| 按闸门 v6 实际路由 | 49 / 55 | 89.1% |
| 假设闸门召回 100% | 51 / 55 | 92.7% |

- 真错 8 道；贵模型修好 4 道（3、22、10、49），弄坏 0 道，仍错 4 道（42、46、47、52）
- 闸门 v6：标出 10 道，TP 5、误杀 5、漏判 3，**精确率 50%、召回 62%**
- 「闸门召回 100%」与「实际路由」相差 2 道，即漏判的全部代价

## 两个结论

1. **路由成立**：贵模型修好一半错题，且不引入新错；只有 8/55 走贵模型。
2. **瓶颈在闸门**：漏判让错题根本进不了贵模型，误杀浪费调用。改闸门比换更贵的模型收益大。

## 闸门的已知缺陷与修复轨迹

| 版本 | 问题 | 后果 |
|---|---|---|
| v1 | 只比「像不像 gold」 | 判 47 对，人工基准 41 对，过松 |
| v2/v3 | 把必需的 `Sources: 文件名` 当编造 | 虚增 16 个假错 |
| v4 | 剔除来源行 + 内部矛盾单列 | 与人工裁定一致率 84.3%（43/51） |
| v5 | 「并列展示互相矛盾的来源」不算自相矛盾 | 一致率 86.3%（44/51） |
| v6 | 支持评审批准的等价答案（gold 修订层） | 对真值精确率 50%、召回 62% |

**判分本身不稳定**：同一批答案、同一提示词、temperature=0，v4→v6 之间有 4 道从对翻成错、2 道从错翻成对。单次判定不可作为决策依据，必须多次投票。

## 改进方向

1. 输出结构从「一个笼统对错」改成「gold 要点逐条覆盖表 + 矛盾列表」，由规则合成 `core` / `detail`，再叠 3 次多数投票；目标召回 ≥ 90%。
2. 加不依赖模型的确定性检查：弃答句式检测、答案实体 ⊆ 证据实体校验。
3. 检索侧：目标实体是否命中召回段落、图表数据是否进了上下文。
