# S8-8 路由闸门实验（2026-10-25）

> 隐私说明：本文只记录方法与结果，不含题目原文、gold 答案与模型输出。评测数据保存在 `var/`（未入库）。

## 目的

验证「先用便宜模型跑全部题，再把错题交给贵模型重答」这条路由是否成立，并量出闸门（判定哪些题算错）的精度。

## 设置

| 项 | 值 |
|---|---|
| 题集 | S8-8 R2 的 55 题 |
| 提示词 | 两侧一致，`EN_SYSTEM_PROMPT`（1257 字符），经只读挂载注入容器 |
| cheap | `XingChenAGI/Xing4.0-29B`，`CHEAP_ONLY` 通道 |
| expensive | `deepseek-flash`，`EXPENSIVE_ONLY` 通道 |
| 路由对象 | cheap 轮被判错的 8 题 |

两条通道共用同一数据库、同一检索配置、同一镜像，唯一变量是模型角色。

## 结果

| 指标 | 值 |
|---|---|
| cheap 完成 | 55/55，一次通过，零重试，中位 8.8 s |
| 路由题 | 8 题，贵模型 8/8 一次通过，3.1–7.9 s |
| 修好 | 2 题 |
| 弄坏 | 0 题 |
| 仍错 | 2 题（1 题为标注歧义，1 题为证据未覆盖） |
| 闸门精确率 | 4/8 = 50%（4 道误杀） |
| 闸门漏判 | 0 |

## 两个结论

1. **路由成立且便宜**：14.5% 的题走贵模型，修好 2 道，未引入新错。
2. **瓶颈在闸门而非贵模型**：50% 的精确率意味着一半贵模型调用是浪费的。提高闸门精度比换更贵的模型收益更大。

## 闸门的已知缺陷与修复

| 版本 | 问题 | 后果 |
|---|---|---|
| v1 | 只比「像不像 gold」 | 判 47 对，人工基准 41 对，过松 |
| v2/v3 | 把必需的 `Sources: 文件名` 当编造 | 英文提示词那轮虚增 16 个假错 |
| v4 | 剔除来源行 + 内部矛盾单列 | 与人工裁定一致率 84.3%（43/51） |
| v5 | 「并列展示互相矛盾的来源」不算自相矛盾 | 一致率 86.3%（44/51），漏判 4→3 |

v5 仍残留的一类误杀：清单题漏一两个子项。判定结构需要从「一个笼统对错」改成
「要点覆盖表 + 矛盾列表」两栏，让 `core` 与 `detail` 分开计。

## 两道仍错的题

- **标注歧义**：同一段文献里同时存在「1979 年成立前身机构」与「1995 年更名」两个事实，原 gold 取前者，两个模型都取后者。已加入 `gold-fixups.json` 修订层，两种表述均判正确，原始标注保留可回退。
- **证据未覆盖**：该题的标准答案是一个地名，cheap 编成同州另一地名，expensive 直接弃答。两个模型在同一份证据上朝两个方向错，属于检索侧问题，不是模型能力问题。
