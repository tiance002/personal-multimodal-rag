## 路由结论

本次样本不足以校准或修改 P5。Cheap 生成后的错误/不确定性线索可以用于提出后续候选策略，但这些线索在首次路由时尚不可用；不能把 Gold 或人工复核标签当作上线特征。现有阈值保持不变，需另行设计只使用线上可观察特征的离线回放与前瞻验证。

## 前端配置需求审查状态

本轮只完成需求设计审查，没有实现或切换配置。后续实现应复用现有知识库配置与模型配置接口，分别管理问答 Prompt 与图片 Caption Prompt，提供默认/保存/恢复默认、VLM 输出上限及受支持模型的推理模式；每个后台任务冻结有效配置版本并记录请求哈希。对 `finish_reason=length` 应显式标记截断，并由用户确认后才允许重新处理。MinerU OCR 指令应与图片 Caption Prompt 分开管理，后端继续负责权限、来源、模型上限和安全校验。
